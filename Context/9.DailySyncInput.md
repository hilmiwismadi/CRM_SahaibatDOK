# 9. Input "Ringkasan Claude" harian (`/sync/dailylog`)

Dibuat 2026-10-07. Dokumen pendamping: `ContinueSession/CRM Sync Pipeline.md` (SOP sync keseluruhan, §2 langkah 1 & §6 query chat).

## Tujuan
Kolom **Ringkasan Claude** di `http://103.93.162.31:3000/sync/dailylog` diisi dari tabel `sync_daily_summaries` (`lead_id`, `date` string WIB `YYYY-MM-DD`, `summary`; unik per `(lead_id,date)`). Halaman dan API (`GET /api/sync/dailylog?date=…`) **hanya membaca**; tidak ada endpoint tulis, tidak ada tombol, dan tidak memakai API berbayar (keputusan 2026-10-01). Ringkasan ditulis oleh sesi Claude Code lewat SQL.

## Alur
1. **Ambil daftar lead + chat hari itu.** Dari browser yang sudah bisa membuka VPS (halaman tidak butuh login):
   - `GET /api/sync/dailylog?date=<tgl>` → `leadId`, nama, phone, kategori, `claudeSummary` (null = belum diisi).
   - `GET /api/conversations` → cari `lead.id` yang cocok → `id` percakapan.
   - `GET /api/conversations/<id>/messages` → `{contact, messages[]}` (`direction` inbound/outbound, `body`, `timestamp`/`createdAt`). Filter ke tanggal WIB yang dimaksud (`toLocaleDateString('sv',{timeZone:'Asia/Jakarta'})`).
   - Alternatif: query SQL di `CRM Sync Pipeline.md` §6 via ssh+psql.
2. **Tulis ringkasan** ke `scripts/crm-sync/summaries/<tgl>.json`:
   ```json
   { "date": "2026-10-07", "rows": [ { "leadId": "<uuid>", "name": "…", "summary": "…" } ] }
   ```
   Gaya (lihat 10-06 di halaman): 1–2 kalimat Indonesia, fakta saja — siapa yang menjawab, apa permintaan/jawaban mereka, tindak lanjut kami (mis. "akan chat ulang tanggal 19"), dan "belum ada balasan" bila belum. Tidak mengarang; bila pesan terpotong, tulis hanya yang terbaca. Satu lead = satu baris (gabungkan bila lead punya dua nomor).
3. **Generate SQL** (lokal, tanpa akses jaringan):
   ```
   node scripts/crm-sync/build-summary-sql.mjs 2026-10-07
   ```
   Menghasilkan `summaries/<tgl>.sql`: `BEGIN; INSERT … ON CONFLICT (lead_id,date) DO NOTHING; COMMIT;` + hitung baris. Teks memakai dollar-quoting `$q$…$q$`; script menolak leadId tidak valid/duplikat, ringkasan kosong, dan teks yang memuat `$q$`.
4. **Terapkan di VPS** (jalankan user lewat `! …`, atau sesi Claude bila ada izin; ssh/psql ke prod pernah ditolak classifier auto-mode — jangan diakali):
   ```
   scp -i VPS_DW/DWSSH.pem Mapping/scripts/crm-sync/summaries/2026-10-07.sql DzakiWismadi@103.93.162.31:/tmp/
   ssh -i VPS_DW/DWSSH.pem DzakiWismadi@103.93.162.31 "docker exec -i mapping-db-1 psql -U sahaibat -d sahaibat_mapping < /tmp/2026-10-07.sql"
   ```
   Hasil yang diharapkan: `INSERT 0 16`, `COMMIT`, `rows_for_date = 16`.
5. **Verifikasi**: buka `/sync/dailylog`, pilih tanggal, **Ctrl+F5** → kolom Ringkasan terisi, tombol "Pakai →" aktif. Atau `GET /api/sync/dailylog?date=<tgl>` → tidak ada `claudeSummary: null`.
6. Lanjut SOP sync: edit script, dry run `APPLY=false`, paste ke console `sales.sahaibat.com` (`CRM Sync Pipeline.md` §2).

## Catatan
- `ON CONFLICT DO NOTHING`: menjalankan ulang tidak menimpa. Untuk **mengoreksi** ringkasan yang sudah ada, ganti ke `DO UPDATE SET summary = EXCLUDED.summary, updated_at = now()` di SQL (atau `DELETE` baris lalu insert ulang).
- Ringkasan hanya boleh memuat isi chat, bukan data sensitif tambahan; tidak menyertakan kredensial VPS (`VPS_DW\Note.txt` + `DWSSH.pem` tetap di luar repo/dokumen).
